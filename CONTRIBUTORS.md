## Contribution Categories

Contributors are recognized for:

- 💻 **Code** — Pull requests and commits
- 📖 **Documentation** — README, guides, inline docs
- 🐛 **Bug reports** — Issues filed
- 💡 **Ideas** — Feature suggestions and discussions
- 🛡️ **Security** — Vulnerability reports
